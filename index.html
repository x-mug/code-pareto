    口径与算法

    得分怎么来的

    能力支柱直接取 Artificial Analysis Engineering Index 页面公开的子分数（0–100）： Agentic Coding = FrontierCode 2.0 与 Terminal-Bench 4.0 等权；Agentic Knowledge Work = AA-Briefcase； Science、Reasoning、Knowledge 同理。默认「纯编程」只取 Agentic Coding 一支。

    成本怎么算的

    用 AA 公开的评测 token 消耗 × 官方价格（含缓存命中/写入与推理 token），除以任务数， 再按当前权重做加权平均，复刻 AA 的 “cost per task” 口径。与 AA 自己公布的综合每任务成本误差在 1–3%。

    膝点怎么找的

    先取帕累托前沿（同成本下没有更强的模型），再在「对数成本 × 得分」归一化平面上， 找离首尾连线最远的那个点 —— 也就是再往上加钱、能力提升开始变缓的拐点（Kneedle 思路）。

    要留意

    样本是 AA 完整跑完 9 项评测的 28 个模型，覆盖面不等于全市场； 成本按官方标价估算，实际账单受缓存率与折扣影响；K2 Horizon 当前标价接近 0，属促销/免费档位。

    本页只是可视化与再加权，不产出新数据。评分、成本原始值均来自 Artificial Analysis，版权归其所有。
